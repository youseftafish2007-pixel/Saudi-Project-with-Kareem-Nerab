# PixelHue — Saudi Edition 🇸🇦

Mobile-first color-by-number pixel-art game with 15 Saudi-themed levels. One HTML file, no build step, no dependencies. Open `index.html`.

- **Levels:** Arabic coffee, the Saudi emblem, a Bedouin tent, Al-Ahsa oasis, Red Sea sunset, a camel at sunset, Elephant Rock (AlUla), Jeddah's fountain, Fajr mosque, Ramadan lanterns, the Kaaba (Makkah), the Green Dome (Madinah), the Riyadh skyline, Hegra tombs (AlUla) and the Empty Quarter
- **Tiers:** Easy 20x20, Medium 28x28, Hard 40x40, with star ratings by accuracy
- **Tools:** tap/drag paint, magic Fill bucket, Undo, Hint, Peek, pinch zoom and pan
- **Extras:** dashboard with progress ring and daily streak, settings, light (white + Saudi green) and dark themes
- Progress saves in localStorage
